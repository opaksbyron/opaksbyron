#### [Router Insight](https://github.com/opaksbyron/router-insight)

A local dashboard for `iblai/claw-router`. The router reports what you spent; this answers

#### [claw-router → `GET /events`](https://github.com/opaksbyron/claw-router/tree/feat/routing-events)

The router scores every request across 14 dimensions, then writes one line to stdout and
discards the rest. This keeps the last 200 decisions in a bounded ring and serves them for
inspection.

**77 lines, no new dependencies** — the repo's zero-dependency guarantee holds. Prompt text
excluded by default; CORS is loopback-only.

`Node.js` `zero-dependency`
